# 第1章 Linuxの概要 — ハンズオン

対象範囲: プロセスとカーネル、システムコール、strace によるシステムコールの可視化、
標準 C ライブラリ、静的ライブラリと共有ライブラリ

ルール:

- VM の中では何をしてもかまいません(man、Web 検索も自由)
- ただし `/etc/handson/` 以下を直接読むのは反則です(修正タスクの答え合わせ用)
- フラグは `flag{...}` の形式です。取得したら VM 上で `submit 'flag{...}'` を実行してください
  (採点サーバーがあるときは正解すると Slack に自動でお祝いが流れます。
  ないときはその場でローカル採点されます)

## 問題1(CTF): 捨てられたフラグ

`/opt/handson/ch01/oracle` は、実行するとあなた専用のフラグを計算するプログラムです。
ただし作者はフラグを画面に表示せず、**どこかに捨ててしまう**ようにしました。

```
$ /opt/handson/ch01/oracle
計算が完了しました。結果は安全な場所に保存されています。
```

`strings` でバイナリを覗いてもフラグは出てきません。
このプログラムが**カーネルに何を依頼しているか**を観察して、フラグを回収してください。

> ヒント: 1章「システムコール発行の可視化」。
> 表示が `...` で途切れて見えるときは、そのコマンドのオプションを調べてみましょう。

## 問題2(修正): 起動しない greeter

`/opt/handson/ch01/greeter` は本来こう動くはずのプログラムです。

```
$ /opt/handson/ch01/greeter
Hello from libgreet!
```

ところが今は起動すらしません。原因を調査し、**恒久的に**修復してください。
修復できると **30秒以内に自動で判定されて通知が届き、フラグも自動提出されます**。
待ちきれないときや途中経過を見たいときは手動でも判定できます。

```
$ sudo ch01-check
```

> 注意: 判定はクリーンな環境変数で実行されます。
> シェルの環境変数で一時的にしのぐ方法では合格になりません。
